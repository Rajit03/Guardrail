# Guardrail

> **Security guardrails for growing businesses.**

Guardrail is a cybersecurity platform designed for small and growing businesses that do not have dedicated security teams.

The long-term product will identify, prioritize, explain, and help remediate security risks across source code, dependencies, cloud infrastructure, identities, and connected services.

## Technology Stack

### Frontend
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router v6
- **HTTP Client:** Axios (with request/response interceptors)
- **Icons:** Lucide React

### Backend
- **Framework:** Python 3.12+ / FastAPI
- **ORM:** SQLAlchemy 2.0
- **Database:** PostgreSQL 16
- **Migrations:** Alembic
- **Auth & Security:** JWT tokens (`python-jose`), Argon2id password hashing (`argon2-cffi`)
- **Scanners:** Gitleaks adapter (Secret Detection), OSV.dev batch API adapter (Dependency Vulnerabilities)
- **Engine:** Deterministic multi-factor Risk Engine (Severity, Exploitability, Exposure, Criticality, Confidence)

## API Reference

| Method | Endpoint | Auth | Description |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | No | Service health check |
| `POST` | `/api/auth/register` | No | Register a new user account |
| `POST` | `/api/auth/login` | No | Authenticate user & return JWT token |
| `GET` | `/api/auth/me` | Yes (Bearer) | Get profile of currently authenticated user |
| `POST` | `/api/repositories` | Yes (Bearer) | Connect a public GitHub repository |
| `GET` | `/api/repositories` | Yes (Bearer) | List user repositories |
| `GET` | `/api/repositories/{id}` | Yes (Bearer) | Get repository details |
| `DELETE` | `/api/repositories/{id}` | Yes (Bearer) | Delete repository and associated data |
| `POST` | `/api/repositories/{id}/scan` | Yes (Bearer) | Trigger a security scan on repository |
| `GET` | `/api/repositories/{id}/scans` | Yes (Bearer) | Get scan history for repository |
| `GET` | `/api/scans/{scan_id}` | Yes (Bearer) | Get scan status details |
| `GET` | `/api/scans/{scan_id}/findings` | Yes (Bearer) | Get findings generated by specific scan |
| `GET` | `/api/findings` | Yes (Bearer) | List findings with filters (`risk_level`, `priority`, `severity`, `type`, `status`) and sorting |
| `GET` | `/api/findings/{id}` | Yes (Bearer) | Get details of a specific finding including risk assessment |
| `GET` | `/api/findings/{id}/risk` | Yes (Bearer) | Get risk assessment details for a finding |
| `POST` | `/api/findings/{id}/risk/recalculate` | Yes (Bearer) | Recalculate risk assessment for a finding |
| `POST` | `/api/repositories/{id}/risk/recalculate` | Yes (Bearer) | Recalculate risk assessments for all repository findings |

## Getting Started

### Prerequisites
- Docker & Docker Compose
- Node.js 18+ and Python 3.12+ (for local development)

### Running with Docker Compose

1. Clone the repository.
2. Copy environment template:
   ```bash
   cp .env.example .env
   ```
3. Start containers:
   ```bash
   docker compose up --build
   ```
4. Access the application:
   - **Guardrail Web App:** [http://localhost:5173](http://localhost:5173)
   - **FastAPI OpenAPI Docs:** [http://localhost:8000/docs](http://localhost:8000/docs)
